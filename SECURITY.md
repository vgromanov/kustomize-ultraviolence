# Security

If you discover a security vulnerability, please **do not** open a public issue.

Use [GitHub Security Advisories](https://docs.github.com/en/code-security/security-advisories) for this repository, or contact the maintainers privately if that mechanism is unavailable.

This repository contains **example** Cluster API / Flux layouts only—no live credentials should be committed. If you find accidental sensitive data in the tree, report it immediately.
